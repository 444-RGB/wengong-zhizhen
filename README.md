## 本版可操作流程
1. 当前工况下拉选择INC原配置、INC延长等待、P&O。

4. 仿真实验室比较同辐照输入的三组结果，读取1ms回放数据积分计算指标。

8. CSV导入校验数值、时间顺序、必需列、重复文件；最多20000行、5MB，数据会持久保存到runtime。仅用于本项目相同拓扑的仿真数据回放，工况来源自行核实。

## 数据与指标
内置数据来自用户三次Simulink输出，控制与电气周期50微秒；回放每20点抽取，保留6001条1ms记录。工况比较窗口为2.5—4.5模拟秒。窗口平均功率用梯形积分电量/窗口时长计算；统计基于抽取后的数据，与原50微秒诊断可能有微小差异。输入哈希核验时间及辐照逐点一致。不能用此6秒过程证明下一小时预测精度、全年增益或真实MPPT效率。
默认诊断电压750/950V、变化率20kW/s、持续0.03s、忽略前0.3s均为演示阈值，未经厂家或场站标定。功率变化率按至少50ms时间差计算。事件表示已发生的测量越限/快速变化，不是气象事件、设备故障定论或提前预警。
